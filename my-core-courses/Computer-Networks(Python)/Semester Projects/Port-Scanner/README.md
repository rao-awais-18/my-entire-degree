# 🔍 Network Port Scanner (Python)

## 📌 Description
This project is a simple network port scanner developed using Python.  
It scans a target IP address and detects open ports using socket programming.

---

## 🚀 Features
- Open port detection
- Port range scanning
- Fast scanning process
- User-defined target IP
- Terminal-based utility

---

## 🛠 Technologies Used

- Socket Module
- Computer Networks Concepts
