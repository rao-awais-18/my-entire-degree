# 📁 File Transfer System (Python)

## 📌 Description
This project is a Python-based file transfer system that allows clients to send files to a server using socket programming.

---

## 🚀 Features
- File upload functionality
- Client-Server communication
- TCP-based file transfer
- Python socket programming
- Simple and lightweight system

---

## 🛠 Technologies Used
- Python
- Socket Module
- File Handling

---

## 📂 Project Structure

```bash
File-Transfer-System/
│
├── sender.py
├── receiver.py
└── README.md
```

---

## ⚙️ How to Run

### Start Receiver

```bash
python receiver.py
```

### Start Sender

```bash
python sender.py
```
