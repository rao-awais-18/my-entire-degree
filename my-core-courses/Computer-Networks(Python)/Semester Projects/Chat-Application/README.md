# 💬 Chat Application (Python)

## 📌 Description
This project is a real-time chat application developed using Python socket programming.  
It allows multiple clients to connect to a server and communicate with each other in real time.

---

## 🚀 Features
- Multi-client chat system
- Real-time messaging
- Client-Server communication
- Socket programming implementation
- Terminal-based interface

---

## 🛠 Technologies Used
- Python
- Socket Module
- Threading

---

## 📂 Project Structure

```bash
Chat-Application/
│
├── server.py
├── client.py
└── README.md
```

---

## ⚙️ How to Run

### Start Server

```bash
python server.py
```

### Start Client

```bash
python client.py
```
