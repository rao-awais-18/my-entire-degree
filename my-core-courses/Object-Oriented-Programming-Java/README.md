# Object Oriented Programming in Java 🚀

This repository contains a comprehensive collection of Object-Oriented Programming (OOP) concepts implemented in Java, ranging from core fundamentals to practical projects.

## 📌 Overview

This repository is designed to strengthen understanding of:
- Core OOP principles
- Real-world problem solving using Java
- Clean and structured coding practices
- CLI and GUI-based application development

## 🧠 Concepts Covered

- Classes & Objects
- Constructors
- Method Overloading
- Inheritance
- Method Overriding
- Encapsulation
- Abstraction
- Interfaces
- Polymorphism
- File Handling
- Exception Handling
- Basic GUI (Java Swing)

## 📂 Repository Structure

### 🔹 Programs/
Contains small, focused programs demonstrating individual OOP concepts.

### 🔹 Projects/
Contains complete applications combining multiple OOP concepts, including GUI-based applications.

## 💻 Technologies Used
- Java (JDK 8+)
- Java Swing (for GUI)

## ▶️ How to Run

Compile:
javac FileName.java

Run:

java FileName
