# OOP Java Programs 📘

This folder contains individual Java programs demonstrating core Object-Oriented Programming concepts.

## 📌 Topics Covered

- Class & Object Creation
- Constructors
- Method Overloading
- Inheritance
- Method Overriding
- Encapsulation (Getters/Setters)
- Abstraction (Abstract Classes)
- Interfaces
- Polymorphism
- Exception Handling
- File Handling

## 🎯 Purpose

Each program is designed to:
- Focus on a single concept
- Be simple, clear, and easy to understand
- Help build strong OOP fundamentals

## ▶️ How to Run
javac FileName.java
java FileName


## 📁 Examples

- Student Class System
- Bank Account System
- Shape Hierarchy
- Interface Implementation
