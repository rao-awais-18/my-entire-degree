# 💻 Programming Fundamentals (Java)

This directory contains all the material related to the Programming Fundamentals course, implemented using Java.

## 📖 Course Overview

This course focuses on building a strong foundation in programming, covering:

* Basic syntax and structure of Java
* Control structures (loops, conditionals)
* Functions and modular programming
* Arrays and basic data handling
* Problem-solving techniques

## 🎯 Objectives

* Develop logical thinking and problem-solving skills
* Understand core programming concepts
* Write clean and efficient code

## 📂 Contents

This directory is divided into:

* **Programs and Tasks** – Practice problems and lab assignments
* **Projects** – Larger implementations combining multiple concepts

---

This course serves as the foundation for all advanced programming subjects.
